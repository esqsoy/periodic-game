# 주기율표 제로투 챌린지

원자번호를 보고 원소의 영문 이름을 치는 주기율표 암기 게임이다. 맞힐 때마다 도트 캐릭터가 춤추고, 그 원소의 보어 모형과 전자배치가 펼쳐진다. 118개를 다 채우면 화학의 여신이 나타난다.

- 공개 주소: https://esqsoy.github.io/periodic-game/
- 만든 사람: 영신(일산 국어 교습소 STUDY1)과 Claude. Claude와 대화하며 만들었다.
- 설치나 빌드가 필요 없다. HTML 파일 하나에 코드·데이터·스프라이트가 모두 들어 있다.

이 게임은 영신이 Claude와 함께 처음 만든 게임이다. 2주 뒤 영어 단어 게임 [보카고양](https://github.com/esqsoy/vocagoyang)을 만들었고, 오답 재출제·약점 복습·정답 시 보상 연출 같은 뼈대를 이 게임에서 가져갔다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 버전 선택 화면 |
| `periodic-girl.html` | 초기 버전. 단발 소녀 스프라이트, 춤 2.4초 × 2회 |
| `periodic-sweden.html` | 개선 버전. 스웨덴 유니폼 스프라이트(실제 투명 PNG), 춤 3.4초 × 1회 |

두 버전의 코드는 같다. 스프라이트, 춤 속도와 반복 횟수, 스프라이트 설명 주석만 다르다.

## 규칙

- 원자번호가 나오면 원소의 영문 이름을 친다(예: 1 → hydrogen).
- 틀릴 때마다 철자가 한 글자씩 더 보인다. 세 번 틀리면 정답을 보여 주고 넘어간다.
- 틀린 원소는 다시 나온다. **연속 두 번** 맞혀야 칸이 열린다.
- 족힌트를 누르면 같은 족 원소들이 강조된다. 패스할 수도 있다.
- 시작 레벨은 여덟 단계(LV.1 2주기 ~ LV.8 악티늄족)다. 고른 단계 앞의 원소는 미리 열린다.
- 하드 모드에서는 문제마다 30초가 주어진다. 시간이 다 되면 자동으로 패스된다.
- 시작 단계마다 최고 기록이 저장된다(일반·하드 따로).
- 118개를 다 채우면 엔딩이 나온다. 화학의 여신, ☢ 핵 발사 버튼, 약점 복습 모드가 있다. 약점 복습 모드에서는 한 번이라도 틀린 원소만 다시 나온다.

## 화면 구성

- 18×10 주기율표: 원소 분류마다 색이 다르다. 지금 문제인 칸이 깜빡이고, 연 칸에는 작은 보어 모형이 남는다.
- 정답 연출: 보어 모형이 차례대로 펼쳐진다. 핵이 먼저 나오고, 안쪽 껍질은 한꺼번에, 최외각 전자는 하나씩 들어온다. 오비탈 상자도 Madelung 순서대로 켜진다(Cr·Cu 같은 예외 전자배치 반영). 콤보 숫자, 폭죽, 화면 흔들림이 함께 나온다.
- 정보 카드: 원소마다 발견자와 연도가 붙은 'RPG 도감 대사'가 나온다. 원자량·밀도·녹는점·끓는점·원자가·결정구조, 전기음성도·이온화에너지도 보여 준다.
- 주기 안내: 새 주기에 들어서면 '화학의 안내자'가 그 주기의 특징을 짚어 준다.

## 뒷이야기

- 첫 스프라이트는 이미지 생성 도구가 '투명 배경'이라며 준 그림이었다. 그런데 실제로는 투명이 아니라 흰색·연회색 체크무늬가 그려진 RGB 그림이었다. 그래서 초기 버전에는 `keyOutWhite()`가 들어 있다. 그림 가장자리에서부터 페인트 통처럼 흘려 채워 체크무늬만 지우고, 소녀의 흰 티셔츠는 남긴다. 개선 버전의 스웨덴 유니폼 스프라이트는 처음부터 투명 PNG다.
- 제목의 '제로투'는 정답을 맞히면 캐릭터가 추는 춤이다. 초기 버전은 그 템포에 맞춰 2.4초에 두 번 췄다. 개선 버전에서는 3.4초에 한 번으로 줄였다(주석: "느긋한 정답 춤").
